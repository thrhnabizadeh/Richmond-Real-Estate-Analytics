# Richmond Real Estate Market Intelligence

## Project Objective
Analyze housing market trends in Richmond and Henrico, Virginia, to support data-driven real estate decisions.

## Tools
- SQL: Data cleaning and analysis
- Power BI: Interactive dashboards
- Excel: Data preparation

## Planned Analysis
- Home price trends
- Price per square foot
- Days on market
- Sales and inventory trends
- Neighborhood comparisons

## Project Status
In progress — data collection and analysis pending.
